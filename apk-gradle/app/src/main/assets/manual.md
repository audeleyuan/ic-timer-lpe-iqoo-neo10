# 使用手册

本软件免费开源，作者酷安 @散花神木。

## 运行规则

- 每次完整运行前**重启手机**；
- 运行后残留的 ic-timer 进程**不能 kill -9**，只能重启清理；
- 接管 KSU 需要先装好对应管理器的 APK（管理器自身的内核模块由 late-load 加载）。

## 内置偏移（机型 + 版本匹配）

- PD2506 / V2506（Y500）：16.1.15.0、16.1.13.2
- PD2516 / V2516（Y500 Pro）：16.1.11.0
- PD2307 / PD2329 / V2307（iQOO 12）：16.2.11、16.2.20.3、16.2.20.7、16.2.21.1
- PD2417 / V2417（Z9 Turbo+）：16.2.14.1
- PD2324 / V2324A / V2324HA / V2324H / PD2324J（X100 系列）：16.2.12.0、16.2.13.1
- PD2352 / V2352：16.2.17.0
- PD2425 / V2425：16.1.17.10
- DPD2329 / PD2329：16.2.9.2
- PD2339 / V2339：16.2.13.1

列表内机型均已内置 KSU 交接所需的对象地址，无需解析。

## 解析偏移（列表外的 build）

点「解析偏移」，选择该机型的 **boot.img** 或**全量 OTA 包（.zip）**：

- 全量包会自动从 `payload.bin` 里解出 boot 分区（zip64 + zstd 解压），
  并先比对包内的设备与版本和当前手机是否一致，不一致直接拒绝；
- `init_boot` / `vendor_boot` 不含内核，会被拒绝；
- 镜像内核不是 6.1.145 也会拒绝；
- 解析成功会生成 `/data/local/tmp/ic-syms.txt`，之后再点一键越狱。

## 安全模式

勾选后会在提权时禁用全部 KSU 模块（通过管理器自带的 ksud 交接脚本完成）。
